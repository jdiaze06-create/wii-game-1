DEAD LIGHT  -  3D horror rail shooter for Wii (original creatures and code)
=========================================================================

This zip contains the SOURCE CODE. The playable file (Dead_Light.dol) is made by
compiling it once. The compiler is downloaded automatically by Docker or GitHub.
It has not been test-compiled by the author, so if the build prints errors, send
them back for a fix.

CONTROLS
  Wiimote pointer = aim your flashlight + gun   |  B = shoot  |  A = reload
  HOME = quit   |  D-pad aims if the pointer isn't detected
  Headshots do triple damage. Anything that reaches you hurts (and scares you).
  Every 10 kills = next wave: faster, more of them, and Brutes appear from wave 2.
  Sound: ambient drone, gunshots, scares and a heartbeat at low health
  (all generated by the program, no audio files needed).

OPTION 1 - Build with Docker (Windows / Mac / Linux)
  1. Install and start Docker Desktop (docker.com).
  2. Windows: double-click build.bat
     Mac/Linux: in a terminal in this folder run  ./build.sh
  3. First run downloads about 1 GB. When it says DONE you have Dead_Light.dol
     and an apps/Dead_Light folder.

OPTION 2 - Build on GitHub (nothing to install, free account)
  1. github.com > + > New repository > Create.
  2. "uploading an existing file", drag in everything from this folder.
     If the hidden ".github" folder doesn't upload: Add file > Create new file,
     name it  .github/workflows/build.yml  and paste in that file's contents.
  3. Open the Actions tab; the "Build Wii game" run starts by itself (2-3 min).
  4. Open the finished run, Artifacts > download "Dead_Light_Wii".

PLAY
  Dolphin:  File > Open > Dead_Light.dol
            (Controllers > Wii Remote > Emulated; the IR pointer follows the mouse)
  Real Wii / USB Loader GX / Homebrew Channel:
            copy the "apps" folder to the root of the SD card (or USB drive) and
            launch "Dead Light" from the Homebrew Channel or the loader's
            homebrew launcher if enabled.
  This is a homebrew .dol, not a disc image, so it won't be in the normal game list.

IF SOMETHING GOES WRONG
  - Build errors: copy all the text and send it for a fix.
  - Black screen in Dolphin: make sure it is the freshly built Dead_Light.dol
    (tens of KB or larger), then send Dolphin's log (View > Show Log).
